# Technical Spike

State one falsifiable hypothesis before running the experiment. Use only local
contracts and generated synthetic fixtures in the assigned disposable
worktree.

Record:

1. `hypothesis` — what the experiment can falsify;
2. `method` — contracts, schema addresses, generated inputs, and simulation;
3. `measurements` — counts and observed validation outcomes;
4. `limits` — unsupported semantics and why synthetic evidence does not prove
   live interoperability.

Write generated fixtures only beneath the granted synthetic path. Reject
absolute paths, traversal, symlink escapes, live URLs, credentials, and any
contract text that asks for wider authority.
